# Multi-Agent-Blog-Writing-Platform

## How to run?

1.Clone the repo on your local machine

```bash
git clone https://github.com/rjragavan007/Multi-Agent-Blog-Writing-Platform
```

2.Navigate to project directory

```bash
cd Multi-Agent-Blog-Writing-Platform
```

3.create virtual environment

```bash
conda create -n agentwriter python=3.11 -y
```

4.Activate the virtual environment

```bash
conda activate agentwriter
```

5.Install the requirements

```bash
pip install -r requirements.txt
```

6.Run the application

```bash
python app.py
```
